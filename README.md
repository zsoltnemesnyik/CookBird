# CookBird

CookBird is a lightweight web application that helps visitors discover recipes quickly and easily. The app provides a simple interface to browse, search, and explore a variety of dishes.

## Features

- Browse recipes by category
- Search for specific dishes
- Save favourite recipes (stored in localStorage)
- Clean, minimal user interface
- Responsive design for desktop and mobile

## Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Hosting:** Vercel
